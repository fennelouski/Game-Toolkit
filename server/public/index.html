Game Toolkit Themes

A small, git-backed repository of board-game-inspired color schemes for the Game Toolkit app. Static JSON, versioned API, no accounts, no tracking.

API

GET /api/v1/index.json          manifest: id, name, game, tags, 3-color previews
GET /api/v1/themes.json         every full theme document
GET /api/v1/themes/:id          one theme document
GET /api/v1/search?q=wingspan   fuzzy search (never logged)

Adding a theme

Open a pull request adding one file to server/data/themes/<slug>.json. CI validates the schema and WCAG AA contrast; the theme goes live on merge.

Themes are fan-made color schemes inspired by the look of the games they reference. Theme names are descriptive and never use game titles. This project is not affiliated with, endorsed by, or sponsored by any game publisher. No game artwork, logos, or other protected assets are hosted here. Publishers with concerns are welcome to open an issue and we will remove the association promptly.
